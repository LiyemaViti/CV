# 1. Agile Team Charter

### Project purpose
The Event Guide Website is intended to help users discover upcoming events and browse previous events in one place.

### Suggested working agreements to verify
- Communicate progress and blockers to the team.
- Agree on task owners and expected outcomes.
- Use GitHub branches and pull requests to manage changes.
- Keep API changes documented in `API_CONTRACT.md`.
- Test changes before treating a task as finished.
- Respect team members' responsibilities and give timely updates.

## Reflection 
 
“Working on the Event Guide Website helped me understand that a team needs a shared goal and clear responsibilities.”
